# 2026-10-26 A 板 IMU 安装与三维杆臂校正

用户确认：IMU 集成在 A 板，A 板随 PITCH 一起运动；YAW/PITCH 两轴相交。IMU 在轴交点前方约 8.4 cm、上方约 3.7 cm。图中 +x 为跟随正前方，+y 向右。

模块 x前/y右/z下，中位杆臂为 `(0.084,0,-0.037) m`。第四次“上抬枪口”日志确认：静态 raw_a_x 从约 +0.33 变为 -3.90 m/s²，传感器 +X 向后，当前 INS 机体系对应 x后/y右/z上，因此填写 `(-0.084,0,+0.037) m`，取代此前未验证的正 X 假设。私有 G 航向安装偏置同时设为 π，以传感器 -X 表达物理前向；不改公共 INS 或云台闭环。杆臂随 A 板刚性转动，不是始终固定在水平面上的 8.4 cm。尺寸以 IMU 芯片位置为基准，安装轴修正改变后也须核对。

以之前日志 yaw 角速度约 4.45 rad/s 为例，单是这段杆臂的向心加速度幅值 r*omega² 就约 1.66 m/s²，与此前转动时的水平加速度是同一量级。因此不能把转动期间所有加速度都归为 IMU 噪声或直接用静止零偏消除。

## 已落实的软件改动

- MC_IMU_ON_GIMBAL=1、MC_IMU_FOLLOWS_PITCH=1，完整传感器系杆臂为 (-0.084,0,0.037) m；MC_IMU_HEADING_OFFSET_RAD=π；轴交点相对底盘参考中心的独立偏置保持原配置。该方向修正仍须实车复测补偿效果。
- 使用 `a_C=a_I-alpha_N×r_N-omega_N×(omega_N×r_N)`。四元数将杆臂和三轴角速度转到固定 N 系，角加速度按真实样本时间差分，包含 yaw/pitch 耦合项。仅在两轴相交且 IMU 与 A 板刚性连接的条件下适用。
- 未放行融合时也计算校正候选值，用于实车验证，诊断计算与加入 KF 的许可独立。
- 保持 MC_IMU_ACCEL_VALIDATED=0 和 MC_ESTIMATE_ONLY，候选加速度不参与 KF，也不触发主动补偿。
- 状态新增 accel_center_valid（使用原保留字节，结构仍为 444 字节），通道 0 IMU 行打印 corr。配置版本更新为 0x20261026，旧二进制解码保持兼容。
- 回归覆盖平面杆臂、底盘/云台、融合关闭/开启；新增独立 Euler 解析轨迹检查仅 yaw、仅 pitch、组合运动和已知平移加速度。验证高度与耦合项、不吞掉真实平移，并拒绝非法四元数/陀螺样本。

## 下一次采集

重新 F5 烧录后固定底盘，依次记录静止、慢速 yaw、慢速 pitch，动作之间静止 2～3 s。先验证慢速动作，再增加角速度；通道 0 仍是四类文本。

- STATUS 中 accel=0、valid=0、exit=5 是当前诊断配置的预期结果。
- corr=1 表示本帧满足校正计算条件，corr=0 时不把 center_a 当作有效校正值；corr=1 本身不代表标定已通过。
- 未校正模块水平加速度为 (nav_a_x,-nav_a_y)，校正候选为 center_a_x/center_a_y，单位均为 mm/s²。
- 检查有效样本的校正后水平加速度是否更接近零，停止后是否回到原静止残差。INS 加速度低通和角速度差分之间可能存在动态时序误差，因此不能只凭安装尺寸正确就开启融合。
