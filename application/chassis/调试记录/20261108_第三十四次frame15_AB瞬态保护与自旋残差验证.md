# 第三十四次：frame15 A/B 瞬态保护与自旋残差验证

结论：**这批数据支持新版更保守地撤销冲突观测权限，未再记录到上一版约0.1 m/s的反向速度仍被放行；但小陀螺加速度观测没有通过验证，暂不应开启主动KF补偿。** 稳定原地自旋的中心水平加速度RMS仍约0.968 m/s²，与上轮0.945 m/s²接近。必须继续查明动态观测残差来源，不能只提高门控通过率。

本次仅分析和保存报告、脚本、CSV及图表，未修改控制源码、配置或固件，未执行烧录。

## 3. A：瞬态误放行减少，普通平移仍需检查一致性

### 松杆与稳定尾段

识别到8次连续可见的松杆窗口，覆盖两轮前后左右。每次轮速重建速度第一次低于0.02 m/s，均约为松杆采样后0.2 s；第一次低于0.005 m/s约为0.2～0.3 s。这是约10 Hz记录的首次越阈时间，不能当作精确实车停稳时间。

8次窗口最初的电流平移投影均与松杆前运动方向相反，支持基础电机速度环请求了制动。电流投影仅为方向代理，没有标定成牛顿，也不证明没有轮地滑动。当前仍为SHADOW，这些制动不是KF主动追加产生的。

这些窗口中，KF沿原运动方向的最小投影约为−0.016 m/s，仍有小量估计反向；轮速幅值低于0.02 m/s且参考接近0的有效样本中，KF速度峰值约0.0247 m/s。**本次没有再记录到上轮约0.1 m/s反向估计且valid=1的情况**，但仍不能由稀疏日志保证所有短瞬态均已消除。

末尾连续30帧（179.167460～182.067458 s）四轮反馈和平移参考全为0，均 `gate=1 valid=1`，KF速度幅值均值约0.00233 m/s、最大0.00316 m/s；中心水平加速度RMS约0.0509 m/s²。该静态尾段估计较稳定。

### 新速度检查确实出现拒绝记录

`reject_reason=4` 出现在seq24500、24520、24680、25420、25440、25460，共6个日志样本，均 `valid=0`，对应移动加速过程。它表明速度差拒绝路径发生并保持了拒绝状态，**不是恰好发生了6次独立事件**。

这些样本打印出的 `v_res_mmps` 不一定仍大于40 mm/s：拒绝后估计回退，后续新轮速会刷新该诊断；原因字段在整窗重新确认前可继续保留。不能据此认为比较阈值没有执行。

A全部有效帧中，独立从四轮重建的G系速度与KF之差最大约0.0359 m/s。这个接近程度受新增门控约束，不能当作独立的估计精度证明。

### 平移融合尚未完成验收

以参考速度幅值大于0.05 m/s选取214帧运动：118帧 `valid=1`（55.1%），133帧使用加速度，81帧 `gate=2`；原因样本中75帧为窗内积分残差，6帧为速度差拒绝，其余为无冲突/恢复。

本批最大参考约0.474 m/s，上轮A约0.307 m/s；输入轨迹和测试强度不同，且门控变严，不能将55.1%与上轮89.2%直接解释为估计精度下降。它说明现在仍有不少普通平移观测不一致，尚不足以开放全工况主动补偿。

## 5. 新线索：残差不只存在于KF输出

下面比较A静态尾段与B稳定原地自旋，IMU原始加速度指安装轴修正后、尚未去重力的传感器值：

| 指标 | A静态尾段 | B稳定原地自旋 |
| --- | ---: | ---: |
| 原始加速度模长5%～95%分位 / m/s² | 9.793～9.867 | **8.605～11.275** |
| 传感器Z轴加速度标准差 / m/s² | 0.0265 | **0.8579** |
| IMU横滚/俯仰两轴角速度合成RMS / rad/s | 0.00573 | **0.1809** |
| 姿态重力观测被拒绝的采样 | 0/30 | **218/407** |
| 独立静止许可位32 | 30/30 | 0/407 |
| 强制重捕获位64 | 0/30 | 0/407 |

模长不随正交坐标旋转而改变，因此8.6～11.3 m/s²的模长波动不能仅靠调整N/G坐标旋转或KF的Q/R消除。它提示IMU所在位置存在显著动态比力、实际振动/摆动，或传感器/采样链异常；没有外部测量仍不能唯一认定是机械振动。

本批自旋片段没有记录到强制重捕获许可或激活，且多数片段仍有显著残差。由此可判断：**修复强制重捕获路径不足以解决整个问题，不能继续把所有残差都归因于那一条恢复分支。** 对短于日志间隔的激活仍不作绝对保证。

同时需核实几何：当前 `CENTER_GIMBAL_OFFSET_X/Y=0`，即yaw轴相对底盘参考中心的偏置按0处理；IMU到云台两轴交点的杆臂仍为传感器系约 `(-0.084,0,+0.037) m`。这两组量是不同的安装尺寸，前者不能由后者替代。仅凭现有加速度不能反推出唯一正确的偏置。

## 7. 下一步：改变对照条件，避免原样重复采集

1. **保持SHADOW、当前门槛和现车平移分配。** 可以继续带门控记录估计；当前尤其不应开启小陀螺主动KF补偿。门控回退不是完整防滑功能。
2. **优先做两档原地自旋对照。** 以目前 `MC_SPIN_LEGACY_WZ=6000` 为高速，另用4000作较低速度对照，模型目标约5.44 rad/s；每档在同一块地面、相同云台姿态下原地自旋约10～15秒，前后各静置约5秒，暂不叠加平移。保持其余配置相同并用实际 `omega_mradps` 核对速度。这里是下轮试验建议，本次未改宏或生成降速固件。
3. **同步观察IMU/云台安装状态和量几何。** 检查IMU固定、云台俯仰/横滚摆动、轮组接地与松动；测yaw轴相对底盘参考中心的X/Y偏置，并复核两轴交点到MPU6500芯片中心的杆臂。不要把估计拟合出的偏置直接写成实测尺寸。
4. 两档对照比较原始加速度模长、RIGID补偿前后RMS、姿态拒绝比例及 `reject_reason`。若较低转速的动态残差明显减小，继续定位转速相关振动、偏心和模型；即便出现近似角速度平方规律，也不能仅凭两档数据唯一确认偏心量。
5. 待纯自旋观测改善，再用同步地面直线/视频验证平移偏移，以及更有针对性的高速启停数据。单纯再采一份相同的四方向日志，不会补上现在缺少的几何和外部运动证据。
