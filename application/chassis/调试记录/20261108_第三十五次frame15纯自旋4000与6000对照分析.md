# 第三十五次：frame15 纯自旋4000与6000对照

结论：**降到4000后动态残差仍然过大，不能据此开启主动KF补偿。新增发现是：两档里，轮速模型重建角速度与“云台相对编码器＋云台航向变化”推导的底盘角速度存在约25%的稳定尺度差，应优先核实轮径、减速比和轮组几何。** 同时，原始加速度模长仍有明显波动，几何尺度差也不能单独解释所有原地自旋残差。

本次仅分析数据、生成图表和报告，未修改控制源码或配置，未编译或烧录。当前配置文件中的 `MC_SPIN_LEGACY_WZ` 为用户已改成的4000，予以保留。本文6000/4000是旧旋转指令档位，不是6000/4000 rpm。

用户确认第一份为6000、第二份为4000，两组均四轮落地、云台保持相同俯仰角，没有人为抬压枪口或转动云台；有过J-Link短暂断连，没有感到明显晃动、跳动或自行平移。

日志支持两档指令已经生效：稳定纯自旋 `omega_ref_mradps` 分别为8162、5441。两组全部可用帧平移用户输入均为0，均 `fw=20261108 frame=15 mode=2`，且 `cmd_g=ref_g`，没有KF候选补偿追加。

实际轮速模型转速降至约原来的0.666，高频残差却只降至约0.912，即约减少8.8%。独立编码器转速也约降至0.671；如果全部是固定偏心引起、其余条件不变的离心项，幅值应近似随角速度平方缩放到约0.45。本批总残差没有这样的单一缩放关系，**不能将它全部解释为一个固定杆臂偏置，也不能从两档数据拟合一个偏置就写回配置**。这不排除残差中有部分偏心/杆臂成分。

原始加速度模长不受正交坐标旋转改变，且两档分位范围几乎一样。因此，单改N/G坐标旋转或KF的Q/R不会修正这个原始动态输入现象。用户没有感到明显机械晃动，仍不能仅凭日志确定是机械振动；真实动态比力、轮地接触、云台/传感器安装、采样/传感器噪声和姿态去重力都应继续核查。

自旋前最近约10秒的可见静止数据，6000/4000档中心水平加速度RMS仅约0.0323/0.0286 m/s²，原始Z轴标准差约0.0138/0.0178 m/s²，且两组全部有效。问题明显与运动工况相关，不能用单个静止零偏量消除。

## 4. 新发现：转速模型有约25%的尺度差

当前 `omega_mradps` 来自四轮模型，不是独立测量的底盘角速度。采用实际相对角 `theta_BG`（不含输出相位提前）和云台导航航向 `psi_GN`，在同一稳定连续记录间计算：

`omega_heading ≈ wrap(Δpsi_GN)/Δt − wrap(Δtheta_BG)/Δt`。

同时使用YAW全精度 `enc_mdeg` 及其 `enc_t_us` 独立重算相对转速；角度跨±π/360°均取最短增量，不跨日志或时基缺口求导。约0.1 s间隔内的旋转小于π，没有整圈采样混淆。长区间按实际时间加权，减少整数角度量化和任务时序差对平均值的影响。

| 稳定段角速度来源 | 6000档 | 4000档 |
| --- | ---: | ---: |
| 四轮模型 / rad/s | 8.1478 | 5.4293 |
| 相对编码器＋云台航向变化 / rad/s | **10.1499** | **6.8069** |
| 两者比值 | **1.2457** | **1.2537** |
| 单独YAW编码器相对转速 / rad/s | 10.1501 | 6.8070 |
| 云台航向变化平均 / rad/s | 约−0.00010 | 约−0.00013 |

两档比例都约1.25，且云台平均航向基本不动，提示轮速运动学尺度需要实车核验。编码器＋航向推导仍依赖编码器单位/机械传动及姿态航向是否正确，不能将其升级为已经标定的绝对真值，但两个日志角度来源的重算相符，已值得优先处理。

当前配置：半径60 mm（即直径120 mm）、减速比19、轴距350 mm、轮距300 mm，X轮旋转力臂按 `(350+300)/2*cos45°≈229.8 mm` 计算。约25%比例差可能来自有效轮径、减速比、实际轮位/滚动方向或滑移，也要检查yaw编码器机械比例。纯旋转只约束这些参数的组合，不能唯一判断哪一个错误。

一个具体的待核实假设：**如果轮子实际直径约150 mm，而代码按120 mm计算，在其他尺度正确时，实际值会比模型值高约25%（模型值约为实际值的80%）。** 这是比例解释，不是尺寸测量结果，尚未据此将半径改成75 mm。也不能忽略负载下有效滚动半径与标称外径的区别。

此外，当前小陀螺方向提前使用相对编码器角速度，并非直接用轮速模型的 `omega_b`，所以发现尺度差不意味着应同步将13.5 ms提前量乘1.25。当前yaw中心偏置配置为0，修改旋转尺度本身也不会直接消除所有纯自旋水平加速度残差。

## 5. 后续优先级

1. **保持SHADOW及现有门控。** 4000档依然不能批准持续融合；不通过放宽0.04 m/s门槛或提高Kp换取通过率。当前源码4000档可用于继续诊断，降速本身没有完成修复。
2. **先核实机械尺度。** 确认四轮外径/型号、减速机构及轮组接地点中心的实际轴距轮距，特别确认当前60 mm究竟是否为真实半径。轮径尚待实测确认，得到尺寸后才能判断配置修改。必要时同步视频数一圈验证底盘旋转周期，区分模型尺度与编码器机械比例。
3. **再隔离IMU动态输入。** 在同一云台姿态下比较电机使能静止、较低速自旋与当前速度，结合高频RIGID/原始加速度及同步视频；检查IMU固定、传感器/供电/采样时序、云台实际运动和杆臂。即使人眼感觉稳定，也应以输入统计和独立运动证据核实。
4. 几何修改后，先做已知距离的非自旋平移和已知圈数的原地旋转校准，再看加速度积分与轮速Δv是否一致。修改半径等机械尺度还会影响命令单位换算、轮速限制、速度估计及其他控制分支，应重新验证，不能把1.25作为只补在日志中的系数。

无需再次原样重复相同的4000/6000日志；本次已经确认“降速未消除残差”和“运动学尺度差”这两个现象。下一份证据优先是实测轮径/几何和独立旋转周期。
