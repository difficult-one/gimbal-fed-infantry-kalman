## frame17：独立补偿许可

`estimate_valid` 仍只表示现有融合检查通过。新的 `control_ready` 由控制入口单独判定，在 SHADOW 中演算许可和候选补偿；只有显式主动模式且 `control_ready=1` 时，候选补偿才进入轮速参考。

当前暂定工程保护值如下。这些是可配置的控制保护初值，**不替代第 2 步传感器数值验收线，也不构成落地实测通过**。

| 参数 | 当前值 | 用途 |
| --- | ---: | --- |
| `MC_CONTROL_STABLE_S` | 1.0 s | 所有条件连续满足的时间 |
| `MC_CONTROL_VELOCITY_MAX_MPS` | 0.01 m/s | N 系融合速度与真实轮速逆解速度之差 |
| `MC_CONTROL_ACCEL_RESIDUAL_MAX_MPS2` | 0.10 m/s² | 当前前缀及上一完整观测窗的平均加速度不一致程度 |
| `MC_CONTROL_RAMP_S` | 0.5 s | 许可恢复后的补偿渐入时间 |

加速度不一致程度是 `|integral(a_center) − delta(v_wheel)| / 实际窗口时间`，比较独立观测；不以绝对加速度小为要求，因此匹配的真实加减速仍可通过。取当前前缀与上一完整窗的较大值。现有 0.04 m/s 融合拒绝门限保持不变。

仅新到达且可共同使用的轮速/IMU观测推进稳定时间；新鲜度范围内的较慢异步样本允许保持许可，重复使用旧样本不能推进稳定时间。超过新鲜度预算、掉线、观测冲突、时基修复、急停或禁用输出会撤销许可，清空候选追加与渐入历史。模式切换后重新观察稳定窗口。执行器检查包括在线状态、限流/轮速缩放、数值有效性及请求/发送电流差异；保留整数截断余量。

重新获得许可后，补偿按渐入比例及原有 `dv_slew`/向量限幅进入。许可撤销时本周期去掉追加；急停仍直接将四轮参考归零。估计继续消费真实观测，摇杆回中不会清零估计速度，也不构成静止判据。电流 `send` 是软件发送值，不能代替独立测量的实际电流或 CAN 总线送达证据。

OBS 同帧新增字段：

| 字段 | 含义 |
| --- | --- |
| `control_ready` | 当前允许追加；SHADOW 中仅作为候选许可 |
| `control_inhibit` | 阻止原因位，可同时出现多个 |
| `control_good_ms` | 连续稳定的观测时间，最多累计到设定值 |
| `control_blend_x1000` | 渐入比例 0～1000 |
| `control_v_err_mmps` | 融合/轮速速度差模长 |
| `control_a_res_mmps2` | 加速度一致性残差，已按窗口时间归一化 |

`control_inhibit` 位值：1 融合未通过；2 源缺失/过期；4 速度差超限；8 加速度残差超限；16 执行器受限/异常；32 输出禁用；64 模式或输出许可切换；128 稳定时间不足；256 当前为基线或纯估计模式。`control_ready=1` 只表示当前工程保护条件满足，不能替代阶段验收。

公共通信协议、444 字节 `ChassisMotionState` 及历史 MCL1 布局保持兼容。新许可字段加入独立 ObservationState，并与 state 同帧排队。文本解析器要求 frame17 的新增字段完整存在；历史日志仍按原版本和轮径解析。
