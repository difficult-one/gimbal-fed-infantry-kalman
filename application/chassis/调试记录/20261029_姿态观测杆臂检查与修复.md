# 2026-10-29 姿态观测杆臂检查与修复

本轮检查基于第十一次实车日志已确认的 YAW 补偿恶化，未要求重复采集旧版本。已修正姿态观测的处理顺序，并生成 `fw=20261029` 固件。源码检查、解析轨迹与实际 INS/EKF 联合测试均通过；**尚无本版实车日志，不能宣称实车约 42% 的恶化已消除或已经满足融合条件**。

## 检查结论

1. 刚体公式 `alpha×r + omega×(omega×r)`、传感器系杆臂 `(-0.084,0,+0.037) m` 与当前安装约定一致。独立导航系轨迹覆盖纯 YAW、纯 PITCH、耦合旋转、真实平移，没有支持统一翻转符号或修改安装尺寸的证据。
2. MPU6500 初始化表先写 ±2000°/s，随后 `mpu_set_gyro_fsr(2)` 覆盖为 ±1000°/s，与实际换算常数匹配，不存在据此可认定的两倍量程错误。加速度/陀螺均设 20 Hz，但额定延迟不同，不能把它们视作相位绝对一致。
3. **确认了一条有问题的处理路径**：旧 `INS_Task` 把带有杆臂切向/向心加速度的原始加速度交给姿态 EKF，EKF 的重力观测又使用该加速度。缓慢转动时，部分旋转加速度会被解释为倾斜。随后再用已偏移的姿态去重力并扣除完整杆臂项，无法还原被姿态估计吸收的那部分。联合仿真已复现慢 YAW 时补偿后 RMS 比补偿前更大，但不据此认定这是实车全部恶化的唯一原因。
4. **确认了旋转计算不一致**：姿态 EKF 使用一次迭代的快平方根，并在观测更新之后未重新归一化；原去重力/导航投影直接用该四元数，刚体数学层则再次归一化。两条路径没有使用完全相同的单位旋转。现在统一归一化 INS 发布副本，保留 EKF 内部状态与公共角度计算。
5. before/after 软件低通原先分别用 SPI 读取前任务起点时间差、SPI 读取后快照时间差。已在刚体有效时统一使用后者；没有把它当成已测得的硬件采样时间或数据就绪时间。

## 修改后的计算链

`IMURigidPrepare` 在姿态更新前，用本帧角速度和先前 EKF 零偏计算角加速度、切向项、向心项。其角速度与本帧 EKF 预测使用的量一致，避免混入本帧观测更新后的零偏增量。求导方式、时间门槛、角加速度上限和低通常数均未调参。

姿态 EKF 的加速度观测改为 `raw_accel - tangent - centripetal`。这一步只扣除几何上确定的旋转项，不将轮速、零摇杆或固定底盘假设作为姿态观测。真实中心平移仍留在加速度中；仅靠加速度计不能区分长期平移和倾斜，这项可观测性限制仍存在。

更新姿态后，对 INS 四元数副本归一化，再计算重力。`IMURigidProject` 使用已扣杆臂、已去重力的中心加速度低通和投影，不再重复扣除杆臂。旧 `IMURigidUpdate` 接口保留为数学层兼容封装。

原始 `INS.Accel`、快照 `accel_raw` 仍为传感器实测值，方便对比。`[RIGID] before/after` 仍在同一 INS 导航系统计，但本版二者都使用改进后的姿态，因此不能将本版 before 当成旧固件 before 的完全相同基线。

首帧、异常时间或角加速度拒绝时，姿态沿用原始加速度观测，本帧中心加速度无效。未配置杆臂时保留原姿态路径。启停、学习门槛、遥控死区、云台 PID、1.0 m/s 底盘速度上限不变。姿态观测的改变会影响云台所使用的估计反馈，需要实车确认保持效果。

## 验证结果与边界

新增 `tests/test_imu_attitude_lever.py` 与 `tests/imu_attitude_lever_test.c`：直接提取编译实际 `INS_Task` 和坐标变换，链接生产姿态 EKF、KF、刚体数学层，仅替换 SPI、时钟、中断、温控入口。传感器轨迹由独立解析导航系运动生成。

同一归一化姿态链中，对比“EKF 仍接收原始加速度”和“EKF 先扣杆臂”两种顺序，水平中心加速度 RMS（m/s²）如下。此处旧顺序只隔离观测顺序的作用，**不是旧固件全部代码的精确重放**。

| 合成轨迹 | 原始加速度作为姿态观测 | 扣杆臂后作为姿态观测 |
| --- | ---: | ---: |
| 慢 YAW | 0.0003049 | 小于 0.0000001 |
| 启动后趋于匀速 YAW | 0.0103911 | 0.0000001 |
| YAW/PITCH 耦合 | 0.0029192 | 0.0004293 |
| 无旋转真实平移 | 0.0825910 | 0.0825910 |
| 静止、80 Hz 合成陀螺噪声 | 0.0129008 | 0.0128995 |

慢 YAW 的原始观测路径 before RMS 为约 0.0001640，after RMS 为 0.0003049，复现“后者更差”。新路径的改善证明本次修复对该机制有效，不代表已拟合或重现实车全部噪声。耦合运动残差约降 85%；真实平移未被多扣除。噪声用例几乎没有改善，明确说明这次没有解决陀螺差分噪声本身。合成噪声用例不模拟 MPU6500 的完整硬件滤波特性。

另验证发布四元数为单位长度、原始加速度快照保留、超时撤销中心有效性、下一帧恢复、未配置杆臂时回退。既有刚体/时间回卷/非法输入、轮速 KF、编码器辅助学习、诊断格式化和文本/历史二进制解码回归均通过。日志格式和状态大小不变，444 字节状态；历史解码新增 20261029，同时支持旧版本。
