## 已完成的代码

1. `imu_compensation.c/.h`：保存实际参加刚体计算的角加速度、切向项和向心项；按 INS 每帧累积平方和、均值和补偿相关项，每约 1 秒发布一份统计。拒绝首帧、非法输入、异常间隔和过大角加速度的计数单独保留，无效帧不混入 RMS。
2. `chassis.c`、`gimbal.c`、`mpu6500.c`：把原先合在一个 `valid` 中的门槛拆为原因位，保持原有有效条件；数学层再区分目标变化、PITCH 编码器变化、姿态、重力、陀螺和时间等门槛。每项累计命中次数，不会因下次恢复有效而丢掉一次 5 ms 的失败。
3. `chassis.c`：原五行仍约 10 Hz，另外在通道 0 每约 1 秒发送 `[RIGID]` 和 `[AID]` 一包。统计与字符串缓冲放静态区；INS 内不格式化文本、不逐帧开平方。日志任务计算 RMS，RTT 满则整包跳过，不忙等重发。
4. `tools/analyze_imu_diagnostics.py`：读取普通通道 0 文本，显示中文原因、各原因增量和高频加速度 RMS，可同时导出完整 JSON。二进制历史解码器支持新版本并保留旧版本兼容，底盘二进制状态仍为 444 字节。

## 烧录与采集

烧录 `build/basic_framework_ATYPE.elf`，确认通道 0 出现 `fw=20261028`，并且每秒能看到 `[RIGID]`、`[AID]`。不需要切二进制窗口，也没有启用其他通道。

保持左开关下、右开关上，底盘固定，上电标定时保持不动。正常启动后采集约 1～2 分钟即可：

1. 静止 10 秒，建立新的诊断基线。
2. 只转 YAW 约 20 秒，尽量保持 20～30°/s，中间反向前停一下。
3. 松手静止 10 秒。
4. 只上下动 PITCH 约 15 秒。
5. 松手静止 30 秒，确认尾段完整保存。

将含所有七种行前缀的原始文本一起保存即可，不必手动理解原因位。不要只复制 `[IMU]` 或 `[YAW]`，否则会丢失本次新加的证据。若窗口滚动缓存太小，可直接保存通道 0 到文件，避免过去出现的大段缺口。

需要自行查看时，在工程目录运行：

```powershell
python tools/analyze_imu_diagnostics.py "通道0日志.txt" --json "诊断结果.json"
```

## `[RIGID]` 怎么读

`win` 是独立秒窗编号，`start_t_us/end_t_us` 是该窗的真实 INS 采样时间。`n` 为总帧数，`good` 为统计有效帧，`bad` 为被排除帧；`n=good+bad`。采样目标约 1 kHz，但实际频率由时戳决定，不强行假设每窗一定 1000 帧。

| 字段 | 含义与单位 |
| --- | --- |
| `dt_us=min,max` | 窗内记录到的真实采样间隔范围，μs；首帧建历史的间隔不纳入 |
| `reject` | 拒绝位：1=建立历史，2=间隔超范围，4=非法输入/无效结果，8=角加速度超限，16=未配置杆臂；可叠加 |
| `alpha_rms_mradps2` / `alpha_pk_mradps2` | 三轴角加速度 RMS / 绝对峰值，毫弧度/s² |
| `tangent_rms_mmps2` | 三轴切向项 `alpha×r` 的 RMS，mm/s² |
| `centrip_rms_mmps2` | 三轴向心项 `omega×(omega×r)` 的 RMS，mm/s² |
| `tangent_pk_mmps2` / `centrip_pk_mmps2` | 上述切向项 / 向心项的各轴绝对峰值，mm/s² |
| `before_rms_mmps2` / `after_rms_mmps2` | 同帧软件滤波后加速度的 XY RMS，mm/s² |
| `before_mean_mmps2` / `after_mean_mmps2` | 上述同一有效样本集合的 XY 均值，mm/s²，可区分静态偏差和波动 |
| `corr_rms_mmps2` | `before-after` 的 XY RMS，mm/s²，即实际扣除量的导航系效果 |
| `cross_um2ps4` | `mean(before*(before-after))` 的 XY 值乘 1e6，单位为 m²/s⁴ 的百万分之一；与 correction 平方量一起判断是否抵消了原残差 |
| `ddrop` | 从首次诊断尝试以后累计的漏读秒窗和诊断包发送失败数；区别于原五行的 `tdrop` |

角加速度、切向项、向心项是**传感器机体系**三轴；加速度统计是 **INS 导航系 XY**。原 `[IMU] center_a_mmps2` 已转到底盘私有 N 系，Y 反号；两类均值不能直接逐轴相减。本诊断中的 before/after 已统一到同一 INS 导航系，可直接比较。RMS 都没有先减均值。

`good=0` 时不使用统计量，RMS/均值将输出无效整数标记 `-2147483648`；整数超范围仍按原规则饱和。两个 RMS 分量的平方相加再开方，才是水平向量 RMS，不能把两个 RMS 直接相加。

这些统计包含 10 Hz 文本抽样之间的全部有效 INS 帧，因此能检出此前混叠掉的差分噪声。`dt_us` 可定位软件采样间隔异常，不能直接测得 MPU6500 加速度与陀螺内部滤波的相位延迟；仍需结合启停/匀速段与补偿项统计判断，不能只凭 RMS 宣称找到了唯一延迟。

## `[AID]` 怎么读

`now` 为最近一次学习调用的阻断位，`last` 和 `last_t_us` 保留最近一次非零阻断及时间；`now=0` 不等于已经满足完整学习窗口。`settle_ms` 为当前连续等待进度（目标 2 秒），`window_ms` 为当前累计窗口进度（目标 3 秒）。`resets` 仅在已有等待/积累进度被清除时增加，启动建历史不记作一次失败重置。

`hits` 按下表顺序输出 31 个累计命中次数。同一帧可命中多项，不能把所有列相加当作暂停帧数。即使失败只持续一帧，下一秒 `now` 已恢复为 0，计数增量仍保留证据。

| 位号 / hits 下标 | 原因 |
| --- | --- |
| 0 | 未标明具体原因的上游无效 |
| 1 / 2 / 3 | 底盘模式不允许 / 底盘命令过期或缺失 / 底盘有运动命令 |
| 4 / 5 | 车轮离线 / 车轮反馈过期 |
| 6 / 7 | 车轮原始速度不小于 0.5°/s / 滤波速度不小于 1°/s，含非有限值 |
| 8 / 9 / 10 | 底盘静止许可过期 / 启动标定未通过 / 辅助学习被关闭 |
| 11 / 12 / 13 | IMU 无效或过期 / YAW 反馈离线或过期 / PITCH 反馈离线或过期 |
| 14 / 15 / 16 | 遥控离线 / 输入源不是遥控摇杆 / YAW 输入非零 |
| 17 / 18 | 云台不是陀螺模式 / 云台命令过期 |
| 19 / 20 / 21 / 22 | 非法输入或四元数 / 偏离重力 / 角速度超限 / 姿态不允许 |
| 23 / 24 / 25 | 学习采样间隔异常 / YAW 目标变化 / PITCH 目标变化 |
| 26 / 27 | PITCH 编码器单帧变化 / 相对锚点累计变化 |
| 28 / 29 / 30 | YAW 编码器单帧变化 / IMU 航向单帧变化 / 3 秒窗口内编码器平均速度过大 |

例如 `last=0x00000040` 对应位 6。如果计数增量主要出现在此项，就应核对车轮原始反馈或机械微动；若主要在位 25/27，就应核对 PITCH 目标与编码器稳定性。原始 `[WHEEL] dps` 已取整，不能用它显示零来推翻位 6/7 的浮点门槛判定。

采集每次从新启动开始或保留明确的上电边界。脚本按首末计数差统计新增命中；只有一条 AID 时仅有累计值，不会伪造本段增量。
