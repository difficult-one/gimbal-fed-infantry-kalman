# 2026-10-26 YAW 间歇持续右转排查

用户反馈：前次添加遥控 ±10 死区后不再右转；安装方向修正后一次启动又出现持续右转，随后自行恢复正常。一次正常不能证明问题永久消除，当前根因未确定。

代码核对：死区仍在；π 航向偏置与负 X 杆臂只进入底盘私有估计，不写云台目标或公共 INS。加速度融合与主动补偿仍关闭。云台 YAW 直接闭环到 YawTotalAngle，速度反馈为 Gyro[2]；现有姿态 EKF 未在线估计 Z 陀螺零偏。上电静态标定超时后会使用编译期 GzOFFSET，但之前该状态打印被屏蔽。因此遥控残差超过死区、标定回退、温度变化引起的陀螺残差等仍需直接观测。

本次只增加只读诊断，控制参数、±10 死区、IMU 零偏算法、安装参数均保持当前版本。未添加在线自动清零或自动修正，因为运动时误学习零偏会掩盖真实转动。

通道 0 每组原四行后新增 `[YAW]` 行，仍使用一次非阻塞发送。`diag=1` 表示当前带 YAW 诊断的格式；独立 `cmd_t_us` 是最新命令快照时间，不能当作前四行的同一采样时刻。命令反馈来自上一轮云台上报，约落后一个机器人周期，适合判断持续变化，不能用于毫秒级相位比较。

| 字段 | 含义 |
| --- | --- |
| src | 0=无新输入分支，1=遥控，2=图传 |
| online / gmode | 遥控在线状态 / 云台模式，0 为零力矩 |
| rc / used | 实际参与本周期处理的 YAW 摇杆原值 / 死区后输入；遥控回中预期 used=0 |
| ref_mdeg | 最终 YAW 目标角，除以 1000 为 ° |
| fb_mdeg | YawTotalAngle 反馈，除以 1000 为 ° |
| enc_mdeg | YAW 相对底盘单圈编码器角，除以 1000 为 °，跨周需解绕 |
| gz_mdps | 云台现用速度反馈 Gyro[2]，除以 1000 为 °/s |
| temp_mC / cal_temp_mC | 当前温度 / 本次标定退出时温度，除以 1000 为 °C |
| cal | 0=未完成，1=本次静态标定通过，2=超时使用固定零偏 |
| bias_z_urps | 使用的 Z 陀螺初始零偏，除以 1000000 为 rad/s |

下一次烧录后，上电时保持 A 板静止、摇杆回中，记录从启动到 40～60 s 的连续通道 0 文本，不操作 YAW/PITCH。若出现右转，再继续记录到恢复正常，并记录大致时间。暂时先定位这件事，再进行运动补偿标定。

判断时必须联合看：若 used 非零且 ref 持续变化，检查遥控输入及模式；若 used 为零、ref 稳定而编码器持续转动，结合反馈角、陀螺、温度判断 IMU 漂移或控制环问题；若 cal=2，说明确实使用了固定零偏，但仍须验证其与漂移的关系。不能仅凭温度上升或者单一非零陀螺值认定根因，也不能在底盘运动时把相对编码器变化等同于云台绝对转动。

标准 ARM 工程编译成功，格式和差异检查通过；既有未使用 MouseKeySet、libc syscall 与 RWX 链接告警仍在。诊断值尚未从实车读取，未声称故障修复。
