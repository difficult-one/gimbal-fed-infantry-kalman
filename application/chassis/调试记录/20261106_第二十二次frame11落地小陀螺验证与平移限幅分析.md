## 3. 平移慢的直接证据

本组所有记录均为 `cmd_g=ref_g`，两轴最大差为 0。虽然允许输出时 `kp_x1000=100` 且候选 `dv_g` 可非零，`mode=2` 只记录候选量，不追加到电机参考。因此不能把本次慢速解释为融合压低了实际输出。

选取稳定旋转目标 8.162 rad/s、用户平移指令幅值至少 1 m/s 的 486 组：

| 量 | 结果 |
| --- | --- |
| 用户指令幅值均值 | 1.0923 m/s |
| 限幅后参考幅值均值 | 0.1209 m/s |
| KF 返回命令系速度幅值均值 | 0.1188 m/s |
| 参考/用户指令比例均值 | 11.07% |
| `flags=1` | 486/486 组，基础参考被限幅 |
| 四轮实际参考最大值 | 本组整体不超过 35999 °/s |

例如 seq=14180：用户 `1091,0 mm/s`，参考/实际命令 `139,0 mm/s`，估计 `115,-13 mm/s`；四轮参考 `32069,32449,35618,35998 °/s`。一个轮子已贴近 36000 上限，基础参考先被压缩，补偿并未执行。

代码链是 `LimitTwistToWheelSpeed()` → 小陀螺 `TranslationScaleForOmega()`：先保留旋转参考，再按四轮各自剩余转速限制平移。当前纯旋转已经占用约 34033.9 °/s，只剩 1966.1 °/s 的正向余量。以当前轮径/减速比换算，允许平移约 0.108～0.153 m/s，随底盘相对云台角度周期变化，与日志一致。

当前并非电流饱和造成慢速：发送峰值为 2610，低于 8000 上限，`sat` 全程为零。提高电流限值或仅提高 `MC_V_MAX_MPS` 不能释放已经被旋转占用的轮速余量。

## 4. 如何提高平移速度

在轮速上限 36000 °/s、现有几何、旋转优先策略下，按模型计算：

| 旧旋转指令 `MC_SPIN_LEGACY_WZ` | 模型旋转目标 rad/s | 纯旋转转子目标 °/s | 各相对角度允许的平移上限 m/s |
| --- | ---: | ---: | ---: |
| 6000（当前） | 8.162 | 34034 | 0.108～0.153 |
| 5000 | 6.802 | 28362 | 0.421～0.595 |
| 4500 | 6.122 | 25525 | 0.577～0.816 |
| 4000 | 5.442 | 22689 | 0.734～1.000 |

上限区间取各相对角度的可行范围，并叠加 1 m/s 平移配置上限；它是理想模型参考，不是已实测车速。建议下一次先比较 5000：自旋目标约降低 16.7%，平移模型余量约增加到当前的 3.9 倍，仍保留旋转优先和影子模式。若重点是更快平移，可再比较 4500。当前转速是之前用户要求提速到的值，本次仅分析，不自动改变这一行为参数。

## 5. 融合是否已经可以开启

需要区分：轮速＋加速度的估计在本组已经恢复运行；主动速度补偿仍然关闭。

- 稳定旋转目标段，KF 与导航轮速的速度向量差 RMS 约 0.0138 m/s。速度结果没有上一组的冻结/失效，但轮速本来就是 KF 的观测来源，二者接近不是独立定位真值。
- 零平移输入且参考已归零的 122 个旋转样本，返回命令系速度中位幅值约 0.0093 m/s、95% 分位约 0.0146 m/s，最大 0.0601 m/s。最大值可能包含刚停车过渡，不能一概认定为漂移。
- 同一零平移段的中心候选加速度向量 RMS 约 0.973 m/s²。对完全处于稳定旋转目标下的 66 个完整秒窗，导航平面去杆臂前 RMS 约 1.002 m/s²，去杆臂后约 1.014 m/s²，未显示总体波动下降。存在真实震动、实际小位移、姿态误差及差分噪声等多种可能，不能仅凭这些数值确定安装参数错误，也不支持宣称中心加速度已经精确。
- 满输入方向保持至少约 0.5 s 的 479 个样本，估计速度相对参考仍有平均约 7.94° 的方向差；独立从同帧导航轮速转换回命令系后约 7.70°。两者接近，不能归因于融合独有错误，也不能替代外部轨迹测量；轮速采样/速度环延迟、机械轮径/方向标定和实际滑移均可能影响它。用户观察“挺直”与此并不矛盾，但还不能宣布方向误差为零。

当前自旋已达可行轮速边缘，开启速度补偿也不能创造额外轮速能力。优先调整平移与自旋之间的余量，然后保持影子模式检查不同速度下的响应；没有必要仅凭 `valid=1` 立即打开主动融合。

用户随后实测报告小陀螺移动时持续向右偏，前进右偏、后退左偏。这种随运动方向反向的现象符合固定方向相位误差。对本组稳定高速样本，四轮平移响应共同相位拟合为 `-7.81°`，以编码器相对角速度 `-10.18 rad/s` 换算等效 `13.40 ms`。轮速逆解的 `8.14 rad/s` 不能替代编码器相对转速，二者比例约 1.25。

因此 frame=12 增加了只作用于输出运动学的相位提前：`MC_SPIN_PHASE_LEAD_S=0.0135 s`，由 `theta_rate_bg`（编码器相对角度的实际差分）计算 `lead=theta_rate*lead_s`，仅在小陀螺、轮速/命令新鲜、时间有效时使用。它不改变 INS 姿态、KF、融合观测或云台反馈；无效输入、停止、非小陀螺模式均为零提前。独立一阶轮速响应模型中，最大平均方向误差从约 `9.29°` 降至 `1.41°`，但该模型不等于实车验收。
