# 第四十次：frame17 落地纯旋转与右漂分析

用户报告：两次落地纯旋转时底盘持续向右漂约 5–10 cm，其他目视检查未发现异常。本次数据证明落地旋转观测仍未通过，主动补偿没有参与输出；尚不能由日志判定右漂的具体部件或原因。

## 结果

两段稳定旋转各约 44 秒，四轮在线、平移摇杆回中，目标旋转参考均为 6892 mrad/s。统计区间分别为 927.569–971.969 秒和 1058.269–1102.569 秒。

| 指标 | 落地自旋 1 | 落地自旋 2 |
| --- | ---: | ---: |
| 稳定帧 | 444 | 444 |
| 融合有效 `valid=1` | 8/444 | 18/444 |
| 观测冲突 `gate=2` | 420/444 | 408/444 |
| 主动补偿许可 `control_ready=1` | 0/444 | 0/444 |
| 10 Hz 中心水平加速度向量 RMS | 0.781 m/s² | 0.868 m/s² |
| 完整高频 RIGID 窗 / 样本 | 35 / 35054 | 42 / 42063 |
| 高频补偿前 RMS | 0.798 m/s² | 0.855 m/s² |
| 高频补偿后 RMS | 0.806 m/s² | 0.882 m/s² |
| 轮速反解净位移候选 | (0.009, 0.039) m | (0.012, 0.010) m |

影子隔离成立：两份日志中最大 `|cmd_g-ref_g|` 都为 0 mm/s。因此 KF 没有把候选补偿追加到轮速参考，这次实测漂移不是该补偿造成的。轮速反解的两个净位移候选方向和大小也不一致；它假设无滑移，不能替代地面位置真值，更不能解释用户观察到的持续右漂。

高频中心加速度在架空对照约 0.051 m/s²，而落地两次约 0.80 和 0.88 m/s²；落地差异明显，但架空时没有真实底盘自旋，且负载和接触条件改变，所以这只说明异常与落地/真实旋转工况相关，不能据此归因于某个轮子、IMU 或滤波器。高频补偿前后 RMS 均未下降，不支持现在通过改 Q/R、放宽门限或改轮径来处理。

**参考值差异已由轮径更新解释：** 先前架空日志按145 mm外径配置，4000档参考为6575 mrad/s；本次源码 `RADIUS_WHEEL=76 mm`，即152 mm外径，本次参考为6892 mrad/s。`152/145=1.04828`，`6892/6575=1.04859`，两者相差约0.03%。现有4000档旧命令映射使模型角速度参考随半径同比增加，同时保持近似相同的电机转子目标。因此这不是新的档位变化，但两批并非同一个模型参考速度。

这个匹配关系只解释了日志里的角速度参考变化，不证明152 mm就是负载下的有效滚动直径，也不能单独解释持续右漂。若152只是软件参数而实测有效轮径仍为145 mm，轮速反解与模型角速度会整体偏高约4.8%；若实体有效直径确为152 mm，则该档位按设计会对应更高的底盘角速度。应把四轮负载下有效滚动直径确认清楚，再解释轮速和漂移；不能仅凭 `omega_mradps` 与参考值接近验证轮径，因为两者都使用同一轮径参数。

四轮纯旋转目标在两份日志里都是 22689 dps。稳态反馈相对目标的均值误差如下，符号为“实际−目标”：

| 轮位 | 自旋1 / dps | 自旋2 / dps | 重复趋势 |
| --- | ---: | ---: | --- |
| LF | −123 | −152 | 低于目标 |
| RF | +48 | +22 | 高于目标 |
| LB | −83 | −111 | 低于目标 |
| RB | −70 | −99 | 低于目标 |

这给出了下一步的具体调试方向：先确认四轮在负载下的有效滚动半径；若四轮半径一致，就校准逐轮速度跟踪，使同一纯旋转命令下的实际轮缘速度一致。按当前误差做一阶试算，电机目标转速修正约为 LF +138、RF −35、LB +97、RB +84 dps（电机顺序 LF/RF/LB/RB，即 ID 1/4/2/3）。这只是影子数据推得的初值，尚未用于固件，也不能跳过机械/半径核验直接烧录。RF 电流反馈均值约 −31 和 −53 raw、其余轮为正，和轮速差异一起作为检查线索；原始电流未标定为转矩，不能单凭它认定 RF 故障。

## 阶段判断与下一步

第 1 步架空对照显示架空明显改善，落地实际旋转两次都保持较大残差。因此目前不进入主动补偿测试；frame17 继续保持 SHADOW，也不改观测 Q/R、0.04 m/s 门限、轮径、杆臂和滤波参数。

先确认152 mm是否为四轮负载下的实际有效滚动直径，并核对四轮滚子/轮胎接触、轮组松动或偏心、传动阻力和轮位方向。若半径一致、机械无异常，下一次软件调整只针对四轮纯旋转的轮速跟踪，保持 KF SHADOW 和其余参数不变；暂以表中目标转速修正量作为小幅试算。做一次约10秒稳定自旋，用地面网格或固定机位记录底盘中心位移，同时核对四轮实际 dps 是否收敛到相同轮缘速度。实车验收目标暂定为 20秒漂移不超过1 cm、重复两次；若轮速已匹配而仍漂，再转查接地几何/地面与真实位置轨迹。只有底盘本身不再明显漂移后，再单独处理 IMU 观测残差和高频时序；目前不启用 KF 主动补偿。

本次不需要再重复同一设置的长时间自旋，也不应测试主动 KF 补偿。只有落地观测达到第 2 步验收、并完成 frame17 许可验证后，才进入分模式主动测试。
