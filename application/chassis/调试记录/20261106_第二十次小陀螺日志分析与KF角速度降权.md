# 第二十次小陀螺日志分析与 KF 角速度降权

日志确认运行版本为 `fw=20261105 frame=9 mode=3`。这里 `mode=3` 是底盘速度估计器的固定主动补偿模式，不是遥控小陀螺模式。日志含 949 组完整五行快照，`qdrop=0`、`tdrop=1894`；采样间隔约 100 ms，约三分之二的候选日志组未能发出，动作边界只可作有限判断。

## 主要问题

高速小陀螺期间，`omega_ref_mradps` 达到约 `8162`，旋转优先限幅保持了旋转参考，但在约 `1.09 m/s` 的大平移输入下，`ref_g` 常被压至约 `0.08–0.15 m/s`。这是当前轮速上限和旋转优先策略的预期取舍，不是 KF 增益故障。

更需要修的是 KF 速度状态与轮速观测长期不一致。停车尾段 `seq=56300` 时，旋转参考约 `2 mrad/s`、轮速反解约 `(1,1) mm/s`，KF 的 N 系速度仍为 `(-181,7) mm/s`；日志末尾 `seq=56860` 仍为 `(-134,4) mm/s`，此时轮速反解约 `(11,-7) mm/s`，主动补偿仍输出约 `(-2,-13) mm/s`。高速转动时仅根据 IMU 三轴陀螺设定加速度观测方差；云台稳定时 IMU 陀螺不代表底盘自旋角速度，残余中心加速度因此可能持续拖动 KF 速度状态。

此外，旋转段峰值实际电机反馈约 `36266 dps`，比软件参考上限 `36000 dps` 高约 0.7%；参考限幅不能约束速度环瞬态超调。它不解释上述停车速度估计残差，但需在下一组低丢包数据里观察。

## 修改与验证

`frame=10` 将轮速逆解的底盘角速度 `omega_b` 加入加速度观测噪声：在 IMU 随云台安装且四轮有效时，按 `MC_ACCEL_ROTATION_R_GAIN * clamp(omega_b,±40)^2` 继续增大加速度观测方差。轮速观测权重、`Kp=0.1`、旋转优先限幅和功率逻辑不变；不再对零摇杆/零轮速硬清 KF 状态。

新增合成残差回归：固定 `0.15 m/s` 轮速速度并注入低频加速度残差，速度估计 RMS 在静止底盘约 `0.0382 m/s`，在 `8.162 rad/s` 自旋条件下约 `0.0020 m/s`。完整底盘主机测试与 `python tests/test_motion_log_decoder.py` 通过；ARM 构建成功，产物位于 `build/codex_spin_kf/`。这些是软件仿真/编译结果，尚未烧录或实车验证。

下一次烧录确认 `fw=20261105 frame=10 mode=3`。通道 0 保持自旋后松开平移并减速，重点看 `omega_ref_mradps` 接近零后 `v_n_mmps` 是否较快跟随 `vn_mmps` 回零、`dv_g_mmps` 是否减小。为了保留动作切换数据，可把 `MC_LOG_DECIMATION` 暂降至 `60`；`tdrop` 应明显低于本次的 `1894`。
