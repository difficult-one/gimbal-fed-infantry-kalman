# 第三十六次：145 mm轮径标定修正（frame16）

用户确认四个全向轮外径均为145 mm。工程此前使用 `RADIUS_WHEEL=60`，即直径120 mm。本次改为 **半径72.5 mm**，没有用纯自旋数据拟合一个75 mm半径来掩盖剩余误差。

此次已修改代码并生成固件，未烧录硬件。当前仍为单板、X型全向轮、`MC_SHADOW`，保留用户正在测试的旧旋转指令4000。新日志标识为 `fw=20261108 frame=16 mode=2`，七行文本及444字节状态/456字节历史二进制帧布局沿用frame15。

## 1. 修正依据及能解释的范围

轮速换算为：

```text
轮缘速度[m/s] = 转子速度[deg/s] × π/180 × 轮半径[m] / 减速比
正确半径 = 145 / 2 = 72.5 mm = 0.0725 m
比例 = 72.5 / 60 = 1.2083333
6000 deg/s转子速度：0.330694 → 0.399589 m/s轮缘速度
```

取第三十五次报告中同一批连续稳定纯自旋样本，对轮速模型单独按正确半径重算；编码器与云台航向推导值保持不动。表中的轮速均值按用于角速度差分的配对区间统计，与原稳定帧均值的微小差异来自配对权重。

| 指标 | 旧6000档日志 | 旧4000档日志 |
| --- | ---: | ---: |
| 连续角速度差分对 | 419 | 540 |
| 原轮速模型角速度 / rad/s | 8.14780 | 5.42927 |
| 用72.5 mm重算 / rad/s | 9.84526 | 6.56037 |
| 编码器＋航向推导 / rad/s | 10.14992 | 6.80686 |
| 推导值相对重算模型的剩余比例差 | +3.09% | +3.76% |

轮径错误可以解释此前约25%尺度差的大部分，但仍未完全对齐。轴距/轮距与实际接触点、滚动方向、减速比、有效滚动半径、轮地滑移和角度测量尺度仍需核验。不能由纯旋转唯一辨识各个机械参数，也不能直接把这3%～4%写成轮径补偿。

这只是**旧日志轮速运动学的离线重算**，不是新固件实测，也没有重放KF/INS。原日志中的 `hat_g`、`valid`、拒绝次数和中心加速度保持历史含义，不能按1.2083同比“修正”。第三十五次记录的稳定自旋中心加速度RMS仍约0.94～1.06 m/s²，高频累计也支持存在动态残差；轮径修正尚不能证明该残差已消除。

## 2. 代码及行为变化

- `application/robot_def.h`：共享轮半径改为72.5 mm，速控项目适配器向四轮传入0.0725 m；不改通用库为其他车辆提供的示例默认值。
- `chassis_motion_config.h`：日志修订号15→16，保留4000档和现有速度、电流、相位、Q/R、门控参数。
- 主机工程配置与145 mm实车参数同步；物理换算、4000档稳态电机参考、6000档的9 rad/s约束都有实际控制链检查。
- 分析工具识别现车frame≤15的60 mm和frame16的72.5 mm，不用新轮径解释旧日志。未登记版本及不同轮径版本混合输入会报错。

旧公共控制协议继续使用旧单位。未限幅的稳态旧命令，经过“旧单位→SI→轮速”的换算后，轮径在正逆变换中抵消。因此当前4000档的纯自旋电机参考仍约 **22689.28 deg/s**；模型目标由约5.4416变为 **6.57528 rad/s**，不会仅因修正模型而把稳态转子速度提高20.8%。

对于固定的SI平移目标，正确轮径下所需转子速度是旧模型的120/145。现有1 m/s平移上限、3 m/s²斜坡都继续按物理单位执行；同一摇杆输入达到限幅的位置和加速手感可能变化。不能把模型数值变大等同于实车变快，或在没有测量前继续提高速度上限。

若将旧旋转档改回6000，其换算目标为 **9.86292 rad/s**，超过现有 **9 rad/s**总上限，实际参考会先限到9 rad/s。因此新旧6000档不再对应相同稳态转子速度，不能直接当作只改轮径的对照。本次不提高角速度上限。

共享轮径也进入现有力控分支：相同目标轮力所需电机力矩增加20.83%，相同电机力矩推算的轮力变为原来的82.76%。此处属于机械换算同步，力控效果需重新核验；本次没有调试力控或功率限制。

## 4. 下一轮实车采集

保持四轮落地、相同地面/负载、云台俯仰角不变，使用当前4000档和影子模式。操作可分成两个文件：

1. **不跟随平移/停车**：上电静置至少5秒；低至中等摇杆前进约2秒，松杆停稳约3秒；后退、左移、右移分别重复，最后静置10秒。最好用地面标线和视频同时记录距离、耗时、松杆停车位置，以核对米制速度和横向偏移。
2. **4000档纯自旋**：静置5秒；进入小陀螺，平移摇杆保持回中、不人为抬压枪口/转云台，保持约15～20秒；退出后静置10秒。纯自旋稳定目标应约为 `omega_ref_mradps=6575`，四轮 `req_dps` 约22689。不要为了接近旧日志5441而重新调低档位。

采集保留完整STATUS/WHEEL/IMU/KF/YAW/DIR/OBS，以及低频RIGID/AID/CLOCK。若有J-Link断连或暂停，保留原日志并说明发生时段；分析继续按时基代次、完整帧和连续区间分开，不跨缺口求导。

重点复核：新轮速模型角速度与编码器推导是否只剩约3%～4%差异；`center_a_mmps2`与RIGID动态残差是否改善；`dv_now_mmps/v_res_mmps/gate/reject_reason`是否仍频繁冲突；退出自旋后的静止估计是否正常恢复。**当前最大未解决项仍是动态加速度观测与轮速变化不一致，而不是KF增益大小。** 保持影子模式，待新版数据证明观测可信后再决定主动融合补偿。

两份分析工具默认筛选的旋转参考为旧版8162、frame16为6575，可用 `--spin-ref-mradps` 覆盖其他档位。它们的方向/相位统计仅选 `exit=0` 的稳定旋转平移，不能用于计算所有无效帧的通过率，也不能从纯自旋文件直接拟合平移相位；这些现车全向轮脚本不适用于其他麦轮/舵轮配置。
